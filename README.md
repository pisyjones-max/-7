# СТОЛОВАЯ №7 (рабочее название — Медведокалипсис)

Мемный survival-шутер: кубические медведи атакуют столовую №7.
Стек: **Three.js + TypeScript + Vite**, упаковка в APK через **Capacitor**.
Без картинок и звуковых файлов — графика и звук генерируются кодом (быстрый запуск, маленький APK).

## Управление
- Палец слева — ходить (плавающий джойстик). Стрельба автоматическая.
- Кнопка справа — БОРЩ-БОМБА. На ПК: WASD/стрелки + Пробел.

## Запуск на ПК
```
npm install
npm run dev
```

## Сборка APK
Через GitHub: пуш в `main` → Actions → артефакт `medvedokalipsis-debug-apk`.
Локально (нужны JDK 21 и Android SDK):
```
npm run android:apk
```
Файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Структура
- `src/game.ts` — ядро: волны, враги, боссы, оружие, лут, эффекты
- `src/models.ts` — кубические персонажи; `src/level.ts` — столовая
- `src/data.ts` — герои, оружие, медведи, прокачка, шутки, мутатор дня
- `src/ui.ts`, `src/style.css` — меню, HUD, рекорды, магазин героев
- `src/audio.ts` — синтезатор звука и музыка; `src/save.ts` — сохранения
